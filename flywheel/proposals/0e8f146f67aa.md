# yt-dlp-m3u8-format-fallback / ## When to Use
Use when `yt-dlp` fails on hosts like `m2max` with error "Requested format is not available" due to source-only `m3u8` streams.

## 步骤
1. 检查源视频是否仅支持 `m3u8` 流媒体格式。
2. 修改下载命令，添加 `--format "best[ext=mp4]"` 或 `--format "best[protocol=https]"` 以强制适配流。
3. 若仍失败，增加 `--extractor-args "yt-dlp:skip-unavailable-formats"` 跳过不可用格式。
4. 重新执行下载任务并观察日志输出。

## 验证
- 确认命令中包含 `--format` 参数。
- 检查下载目录是否有 `.m3u8` 或合并后的 `.mp4` 文件生成。
- 运行 `yt-dlp --simulate` 预检命令，确认无 "Requested format is not available" 报错。

## 坑
- 盲目添加 `--format` 可能忽略音频分离需求，导致无声视频。
- 某些 `m3u8` 需 `--merge-output-format mp4` 才能合并片段。
- 网络不稳定时 `m3u8` 下载易中断，需配合 `--retries` 参数。
- 部分平台禁止直接下载 `m3u8`，需先转存为临时文件再处理。
