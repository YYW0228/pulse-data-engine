# M3U8 流媒体抓取与转码

## When to Use
Use when `yt-dlp -f bestaudio` fails with "Requested format is not available" on M3U8-only streams.

## 步骤
1. 确认源视频仅包含 `.m3u8` 流，无独立音频文件。
2. 执行 M3U8 直抓命令：`yt-dlp -f "best[ext=m3u8]" [URL]`。
3. 使用 `ffmpeg` 对抓取的 `.m3u8` 文件进行合并与转码：
   `ffmpeg -i output.m3u8 -c:a copy output.mp3` (或按需转码)。

## 验证
- 检查 `yt-dlp` 输出是否包含 `M3U8` 格式下载成功。
- 运行 `ffprobe output.mp3` 确认音频流正常且时长匹配。

## 坑
1. 默认 `-f bestaudio` 会跳过 M3U8 流导致报错，不可直接复用。
2. 部分 M3U8 需先合并再转码，直接转码可能失败。
3. 转码时若未指定 `-c:a copy` 可能导致重编码耗时过长。
4. 抓取的临时文件需清理，避免磁盘占用过大。
