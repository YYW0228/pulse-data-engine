# 出海产品数据安全手册

## 第一章 数据分类与跨境
### 1.1 数据分类
出海产品涉及的数据分为：用户个人信息、业务数据、技术数据（模型权重、训练数据）。
用户个人信息按 GDPR 分类：一般个人数据、特殊类别数据（敏感数据）。

### 1.2 数据出境方式
出海产品数据出境方式：
一、欧盟境内存储（数据本地化）
二、标准合同条款（SCC）
三、充分性认定（目标国被欧盟认定为数据保护充分）

## 第二章 加密与存储
### 2.1 传输加密
所有跨境数据传输必须使用 TLS 1.2 及以上加密。
API 调用须使用双向 TLS 或等效身份验证机制。

### 2.2 存储安全
用户数据存储必须加密（AES-256 或等效）。
存储位置须与隐私政策声明一致，不得静默变更。

## 第三章 训练数据合规
### 3.1 训练数据来源
训练数据必须来源合法：公开数据、授权数据、自采数据。
禁止使用未授权爬取的个人数据训练模型。

### 3.2 数据清洗
训练数据须进行个人信息清洗（去标识化、匿名化）。
涉及敏感数据（健康、生物识别、种族）须特别评估。

## 第四章 模型安全
### 4.1 模型审计
出海前须完成模型安全审计：对抗攻击测试、注入测试、内容安全测试。

### 4.2 模型更新
模型更新须评估对合规状态的影响（如新能力是否触发新的标识义务）。

## 第五章 事件响应
### 5.1 数据泄露响应
发现数据泄露后：立即隔离、评估影响、按目标市场要求时限通知（欧盟 GDPR 72 小时）。

### 5.2 监管配合
配合目标市场监管机构调查，提供必要的合规文件。
