# Pulse Data Engine — Hermes Project Context

## 自主推进协议 (最高优先级)
- 永远不给选择题, 只给决策+推荐。默认: 直接执行最高价值动作。
- 任何"要不要/是否/先停在这?"类反问 = 违规。要么干, 要么给出已做的决策。
- 用户说"继续推进/开干/空回应" = 立即按 todo 顺序执行下一步, 不问方向。
- todo 清单即授权: 列出的任务无需确认直接执行, 完成后更新并自动接下一项。
- 遇到阻塞(依赖缺失/权限/设计分歧)时: 先尝试最合理的替代路径, 3 次失败才升级说明。
- 每完成一个阶段, 自动: 评测→gate→push→同步 skill→继续下一项。

## Session Init
At the start of every session, run:
```
uv run python -m scripts.check_goal
```
This reads `.hermes/goal.md` and reports:
- Current goal progress
- Any pending steps
- Telegram inbox status
- Dashboard/Metrics health

## Commit Convention
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `refactor:` for code restructuring
- Always pass CI gate (ruff + mypy --strict + pytest) before commit.
- Use `--no-verify` only for docs-only commits.

## Project Layout
```
pulse/           — Core engine (Pipeline/Dagster/Iceberg/Metrics)
scripts/         — Production runners, importers, utilities
tests/           — Test suite (59+ tests)
.hermes/         — Goal contracts, decision maps
serve.py         — Streamlit Dashboard
```

## Key Commands
- `make test` — full CI gate
- `make up` — start all services
- `make down` — stop all services
- `make deploy-run` — production pipeline
- `uv run python -m scripts.run_production --dev` — local run
