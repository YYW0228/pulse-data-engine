## 1. 竞品对标

### 1.1 国内市场(阿里云开发者社区, 2026-03)

| 档位 | 价格 | 包含内容 | 周期 |
|---|---|---|---|
| 基础型 Agent | **3–8 万** | Prompt 工程 + 轻量 RAG(≤100 份文档)+ 简单 API 联调 | 2–4 周 |
| 进阶型/行业级 | **15–40 万** | GraphRAG + 多 Agent 协同(2–3 个)+ 定制 UI/小程序前端 | 2–3 月 |
| 企业级定制 | **50–150 万+** | 私有化部署 + 模型微调 + ERP/CRM/数字孪生系统集成 | 4–6 月 |

**持续性费用(行业标准):**
- 年运维费 = 首期开发费 **15%–25%/年**(提示词调优、知识库更新、模型版本兼容)
- Token 成本: 活跃用户约 1–2 元/天(2026 国内主流模型 API 0.001–0.05 元/千 token)
- 变量: 数据清洗 +20% / 多模态(实时语音、视觉)+30% / 合规(算法备案等)额外

### 1.2 国际市场(BlokAI 2025-06, 日本/全球时薪)

| 供给方 | 时薪 |
|---|---|
| 独立顾问(3+ 年经验) | $160–260 |
| 小型 Studio(3–8 人) | $190–360 |
| 中型咨询 | $325–650 |
| Big4/大型咨询 | $520–975+ |

### 1.3 洞察

1. **市场地板价 3–8 万**(基础型)。白云设想的「几千到几万」处于地板以下 → 走**价格渗透 + 极速交付**路线可行,但需用档位化避免自我贬低。
2. 老板要的是「**能跑、能省人、能演示**」: 交付物 = 可运行 demo + 部署文档 + 维护说明。这正是 Hermes 自主代理管线的强项 —— 我们可以在 3–8 万档交付部分 15–40 万档能力(多 agent 脚手架 + 日志/权限/成本控制)。
3. 收费结构必须含**年度运维费(15–25%)**,把一次性项目变成持续收入;这是行业已教育好的习惯,直接借用。
4. 2025→2026 市场信号: 客户从「探索模型能力」转向「为业务价值付费」(IDC), 封装成行业应用的 agent 工程化是买单点。

## 2. 服务包设计(demo → 框架 → 培训 漏斗)

### Tier 0: 诊断获客 — ¥5,000–10,000
- 现有流程审计 → AI 落地点位识别 → ROI 预估
- 交付: 一页纸诊断报告 + 10 分钟演示 demo(轻量, 单场景跑通)
- 作用: 低价破冰, 为 Tier 1/2 蓄客

### Tier 1: MVP Demo(轻量单场景)— ¥1–3 万
- 单业务场景 agent(智能客服 / 文档处理 / 报表生成 / 简单审批)
- 技术: 云端模型 API + 轻量 RAG + 基础日志/权限
- 周期: 1–2 周; 交付: **可运行 demo + 部署文档 + 一页维护说明**
- 目标客户: 想「先看看效果」的老板

### Tier 2: 落地框架(生产化)— ¥5–15 万
- Hermes 脚手架定制: 模型封装 + RAG + 工具调用(function calling)+ 日志/权限/**成本控制** + 简单前端
- 2–3 个业务场景; 周期: 3–6 周
- 交付: 生产化框架 + 部署文档 + 维护说明 + **1 次现场培训(半天)**
- 目标客户: 已确认 ROI 的中小企业

### Tier 3: 持续运维与扩展 — 年费 = 实施费 15–25%
- 知识库定期更新、prompt 调优、模型版本升级兼容、新场景扩展
- 把一次性项目转为订阅收入; 续约率即护城河

**漏斗逻辑**: Tier 0 获客 → Tier 1 验证 → Tier 2 收款 → Tier 3 续费。
**差异化卖点**: 自主代理管线 → 交付快(行业周期的一半)、成本低、可演示性高。
