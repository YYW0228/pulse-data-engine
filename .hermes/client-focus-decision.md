# 客户方向收敛决策 — 外贸企业 AI 化 (2026-08-12)

> 背景: 白云提出拓展方向 = 科技/AI 工程 + 教育 + 外贸; 要求收敛建议
> 裁决: **主攻外贸企业 AI 化** (B2B 外贸工厂 + 跨境电商); AI 出海小公司为次选交集 (acme 同圈转介绍)

## 一、三板块对比 (基于 harness 资产匹配度)

| 维度 | 科技/AI 工程 | 教育 | 外贸 |
|------|-------------|------|------|
| 痛点强度 | 中 (缺时间不缺能力) | 中 (内容责任风险) | 高 (询盘/多语言/跟单重复人力) |
| 决策链 | 慢 (工程师评估, 视为竞品) | 招投标/预算管制 | 快 (老板直接拍板) |
| 付费意愿 | 中 | 低 (政策阴影) | 高 (工具付费习惯) |
| AI 成熟度 | 高 (卖时间不卖能力) | 巨头免费工具渗透 | 低 (多数只用 ChatGPT 翻译) |
| ROI 直观度 | 低 (验收模糊) | 中 | 极高 (1 业务员月 8-15K, 省人力秒懂) |
| 合规钩子 | 无 | 无 | GDPR/欧盟客户数据 (8502 对口) |
| 竞争 | 开源工具链 | 讯飞/有道/作业帮 | 外贸 SaaS 仅 CRM/获客, AI 定制渗透低 |
| 转介绍 | — | — | 产业带/商会/展会圈层密 |

## 二、裁决逻辑

1. 决策快 + 付费好: Tier 0 ¥5,800 → Tier 1 ¥18K 询盘助手, 正卡外贸老板决策区间
2. 场景对口 harness: 多语言询盘初回复 (RAG+产品知识库) / 客户分类打标 / 海外市场洞察 (Pulse 管道) / 产品描述批量生成
3. 合规付费刚需: GDPR + 出口管制 → 8502 引擎 + customer-data-compliance.md 直接卖
4. 无巨头威胁: 外贸 AI 定制服务市场分散
5. 转介绍生态: 一个案例吃一个圈 (产业带/商会/展会)

## 三、明确排除

- 教育: 双减阴影 + 内容责任风险 + 巨头免费工具 + 招投标决策链; 'AI 时代提问力'课程是独立内容生意, 不与 harness 服务混线
- 科技/AI 工程 (整类): 客户有能力自建, 我们卖时间不卖能力, 验收边界模糊; 唯一例外见下

## 四、次选交集 (转介绍来源)

- **AI 出海小公司** (如 acme 同圈): 无工程团队, 需要 AI 能力产品化出海; 本质 = 外贸+AI 交集; 交付形态接近外贸 Tier 1/2
- 路径: acme 演示 → 满意 → 问一句 "你们圈里还有谁需要同样的事" → 裂变

## 五、落地动作 (外贸线)

1. 电销名单 20 家: 深圳/广州产业带 B2B 外贸工厂 + 跨境电商 (行业: 电子/家居/机械/纺织)
2. 场景包定制: 询盘助手 demo (英文询盘 → 分类+初回复+报价提示) — 用 acme 场景改造成外贸版
3. 合规钩子: GDPR 问答 demo (8502 已具备) — 外贸客户的差异化武器
4. 话术调整: pricing-and-outreach.md 的异议处理加外贸专属 2 条 (询盘质量/时差跟单)
5. 市场洞察: 用 Pulse 岗位数据做"外贸业务员人力成本"一页纸 (获客钩子, 替代 AI 岗位数据)
