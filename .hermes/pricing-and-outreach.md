**定价锚点话术**: 「市场基础型代理 3-8 万, 我们 Tier 1 从 1.8 万起步, 因为我们的交付管线是自动化的, 同样的东西交付周期是行业一半。你可以先花 5,800 买个确定性, 再决定要不要继续。」

**谈判底线** (授权区间, 不超):
- Tier 1: 最低 ¥14,000 (7.5 折), 条件 = 签 Tier 3 年费
- Tier 0 可抵扣 Tier 1 首款 50% (即升级时诊断费 50% 退)
- 拒绝: 纯工时报价 / 先干后谈 / 无限改需求 (超 2 轮变更走增量报价)

**报价必须含** (防后期扯皮):
- 数据量假设: ≤100 份文档, 超出按 ¥500/100 份
- 模型 API 用量: 客户承担或代管 +5% 服务费
- 变更: 超出原定场景范围的需求 = 增量报价, 单次 ≥¥2,000

## 二、客户沟通脚本 (电销 Tier 0/1)

### 目标客户画像 (只打这些)
- 年营收 500 万-5 亿, 有 2+ 员工在处理重复文档/客服/报表工作
- 已听说过 AI 但没落地 ("试过 ChatGPT 觉得不行" 是常见开场)
- 决策人: 老板 / 运营负责人 (非 IT 总监 — IT 会先卡安全合规)

### 电销 5 步脚本

**Step 1 开场白 (15 秒, 只讲价值不讲产品)**
> 「王总您好, 我是星才科技的白云。不耽误您时间, 就一件事: 最近我们用真实岗位数据和企业案例做了 AI 落地调研, 发现像您这个行业, 有 3 个环节是 AI 能直接省人力的。您方便给我 3 分钟, 我给您说下是哪 3 个吗?」

- 关键: 说"3 分钟"不说"介绍产品"; 用"调研/发现"建立专家位; 报数据来源 (真实岗位数据 = Pulse 引擎)

**Step 2 需求挖掘 (3 个问题, 问完就闭嘴)**
> 1. 「您团队现在最花时间、最重复的活儿是什么?」
> 2. 「这事现在几个人在做? 一个月大概占他们多少时间?」
> 3. 「如果这个环节能省一半人力, 您会想先看个效果吗?」

- 记录: 场景名 + 人数 + 工时 → 这就是报价依据 (1 人月成本 ≥ ¥10K → Tier 1 有戏)

**Step 3 痛点对齐 (把他们的场景映射到我们验证过的场景)**
> 「您说的这个, 我们正好有一套已经跑通的方案, 和您这个场景几乎一样 (比如: 合规文档问答 / 客户咨询自动回复 / 报表自动生成)。我们做了个 demo, 1 分钟给您看一眼效果?」

- 武器: acme 演示包 (证据包 PDF + demo 10/10) — 直接甩链接/录屏, 不要口头描述

**Step 4 报价 (先 Tier 0, 给确定性)**
> 「看效果分两步。第一步花 ¥5,800, 我给您做一次 AI 落地诊断: 两个访谈, 出一页纸报告, 告诉您哪 3 个环节最值得上 AI, 预计省多少人。报告您拿去跟谁聊都有用。诊断完您觉得靠谱, 再谈第二步的方案, 一般 1-2 万起, 2 周交付。」

- 关键: 报价必带 3 件套 (金额 + 交付物 + 时间); 先说诊断再说方案, 永远不先报价 Tier 1

**Step 5 异议处理 (5 个高频异议, 背下来)**

| 异议 | 回应 (背熟) |
|------|------------|
| 「我们自己有 IT」 | 「那更简单了, 我们交付的是能跑的框架和文档, 您的 IT 直接接管维护。行业里 IT 最烦的就是没有文档的黑盒, 我们交付物正好补这个。」 |
| 「ChatGPT 我们试过, 不行」 | 「ChatGPT 是通用工具, 你问它答; 我们做的是把您的业务数据接进去, 回答带引用、能追责。差在'用起来'和'信得过'。」 |
| 「太贵了」 | 「理解。所以第一步诊断只要 ¥5,800, 相当于一次咨询费, 报告还是您的。而且我们跟市场比, 同样的交付行业要 3 万起, 我们 1.8 万起是因为管线自动化。」 |
| 「要考虑考虑」 | 「没问题。我给您留个资料包 (证据包 PDF), 您看完如果觉得值得, 我们约 30 分钟, 我直接带 demo 给您演示。资料包我发您微信?」 |
| 「数据安全怎么保证」 | 「我们有书面承诺: 数据不出域、可删除、可审计, 每条回答带溯源。这份承诺文档我发给您, 可以拿给法务看。」 (对应 pulse docs/customer-data-compliance.md) |

### 跟进节奏 (不骚扰但不断联)
- T+1: 发证据包 PDF + demo 链接 (微信/邮件)
- T+3: 电话 1 次 (只问: 报告看了吗, 哪个环节最感兴趣)
- T+7: 发行业专属洞察 (用 Pulse 市场报告里他们行业的数据点 — 这是差异化武器)
- T+14: 最后 1 次: 「下个月我们档期满了, 如果想约诊断, 这周定最合适」
