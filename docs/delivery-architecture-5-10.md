# 交付产品线架构 — 5+10 复用底座 (2026-08-23)

> 范围: 场景 10 (企业第二大脑/知识库问答) + 场景 5 (合同审查) 共用同一底座。
> 场景 1 (外贸单证) 为按需扩展层, 不进入本底座主动开发。
> 主线依据: vault/vertical-agent-100m-scenarios.md 主线对齐分析 (M1 获客漏斗 → 5/10 交付产品线)。

```
┌─────────────────────────────────────────────────────────────┐
│ 输入层                                                       │
│   客户文档 (制度/合同/手册)   全局法规库 (57 文档 + 每日情报)  │
│        │  customer_onboard (5分钟接入, 客户数据隔离)          │
│        ▼                                                     │
│ 解析层                                                       │
│   MinerU (PDF/Word/扫描件多模态)  →  md 分块 (## 锚点)        │
│        ▼                                                     │
│ 知识层                                                       │
│   DuckDB VSS + bge-small-zh 向量库                           │
│   全局库 (法规+情报, kb_refresh 每日 04:00)                  │
│   客户隔离库 (acme.duckdb, 每客户独立, gitignore)            │
│        ▼  top_k=8 (客户库小块分散)                           │
│ 推理层                                                       │

│   llm_audit 不变量: 审计/熔断/循环检测/watchdog               │
│        ▼                                                     │
│ 场景层                                                       │
│   [10] 知识库问答  ← 8502 Streamlit (已验证, demo 13题全命中) │
│   [5]  合同审查    ← 风险条款识别/缺失条款提示 (demo 2题)     │
│   [1]  单证合规    ← P2 按需扩展 (客户需求触发再启动)         │
│        ▼                                                     │
│ 交付层                                                       │
│   私有化部署 | 权限隔离 | 审计日志 | 0.0.0.0 局域网直连       │
└─────────────────────────────────────────────────────────────┘
```

## 复用点 (为什么是同一个底座)

| 能力 | 场景 10 (问答) | 场景 5 (合同审查) |
|------|---------------|------------------|
| 文档解析 | MinerU | MinerU (合同 PDF/扫描件) |
| 向量检索 | DuckDB VSS | 同左 (合同入库即检索) |
| LLM 推理 | DeepSeek + 审计 | 同左 (风险条款识别) |
| 客户接入 | customer_onboard | 同左 (合同放 raw/ 即可) |
| 演示面 | 8502 问答 | demo_ai_export 合同题 |

差异点 (按需扩展, 不破坏底座):
- 场景 5 需补充: 合同模板库 / 条款风险词典 (规则引擎注入)
- 场景 1 需补充: HS 编码 / 海关规则 / 单证模板 (数据资产, P2)

## 部署形态 (交付视角)

- 单客户: 本地/私有化运行, 5 分钟接入 (customer_onboard) → 当天出 demo
- 多客户: 每客户独立 DuckDB (隔离), 全局法规库共享 (情报保鲜是卖点)
- 零计算交付: Worker/R2/WASM 模式可覆盖只读问答场景 (M4 复用)

## 验证状态 (2026-08-23 实测)

- 205 tests 全绿, ruff/mypy 干净
- 合同示范文本: docs/contract-review-sample.md
