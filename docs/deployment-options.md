# 私有化部署选项说明 (对外)

> 版本: v1.0 | 2026-08-02
> 原则: 客户确定部署环境后再定制交付包, 不预测需求

---

## 当前可部署形态

### 形态 A: 单机 systemd (当前生产, 已验证)
```
适用: 客户有 1 台 Linux 服务器 (最低 4GB 内存)
已跑通: 5 服务 (Dashboard/合规问答/WASM/Metrics/Telegram)
        + 崩溃自愈 + 端口管理 + 开机自启
```

### 形态 B: Docker Compose (客户要求时启用)
```
适用: 客户已有容器化基础设施 / 需要标准交付
触发: 第一个真实客户确定需要 Docker 时写 (当前未写, 避免预测需求)
```

### 形态 C: 内网离线包 (信创/涉密环境)
```
适用: 数据严格不出域, 无外网
需评估: 离线模型 (embedding + LLM) 方案
```

## 数据安全承诺

```
✅ 数据不出域: 系统部署在客户环境, 文档/索引/问答全在本地
✅ 全链路审计: 每次问答 trace 可回放, 谁问了什么、依据什么回答
✅ 权限控制: 低置信度回答自动标记"待人工复核"
✅ 不收集: 客户文档不用于任何外部训练
```

## 资源需求 (估算)

```
最低: 4GB 内存, 20GB 磁盘, 2 核 CPU (单机部署)
推荐: 8GB 内存, 50GB 磁盘 (留足文档增长)
模型: embedding 本地 (bge-small-zh) + LLM 可选
      (云端 DeepSeek / 客户私有化模型 / 本地小模型)
```

## 部署时间

```
标准: 1-2 天 (含环境搭建 + 数据接入 + 验收)
定制环境 (Docker/离线): 客户确认后 2-4 天
```
