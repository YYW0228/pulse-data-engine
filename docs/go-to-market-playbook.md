# Go-To-Market Playbook — 外贸企业 AI 治理问答基座

> 版本: 2026-08-26 | 状态: 执行看板 | 来源: SLIP + MBS 框架共识

## 0. 定位一句话

内核(合规问答基座 + 自成长吞噬飞轮)与销售切面(外贸企业 AI 治理问答)分离:
技术层用 domain 隔离防散, 商业层只打一个切面直到击穿。

## 1. MBS 画像卡 (死磕唯一切面)

| 维度 | 定义 |
|---|---|
| 单一痛点 | 老板怕员工乱问 AI 导致违规/数据出境, 需要"带依据、可审计"的内部问答 + 简单培训 |
| 极窄人群 | 已有合规/数字化预算, 近 6 个月用过 ChatGPT/通义/文心等工具, **50-300 人**外贸企业 (深圳/金华/杭州) |
| 预算来源 | 数字化转型/合规项目经费 (¥5.8K 可立项) |
| 决策人 | 老板 (70%) / 总经理 (30%), 决策链路 ≤2 人 |
| 可重复性 | 同类企业痛点一致 → 话术/证据包/演示脚本可复制 (lead-gen 素材复用) |
| 拒绝诱惑 | course/sales/internal-ops 只做技术隔离, 销售话术一律导向外贸合规问答+培训 |

## 2. SLIP 检查清单 (带完成定义)

### S — Simple to Install
- [ ] `deploy_client.sh` 一条命令装完 → **验收: 新 macOS/Linux 从零到 8502 可访问 ≤15 分钟, 零人工干预**
- [ ] 模型打包/国内镜像 → **验收: 断外网也能完成安装** (离线模式)
- [ ] `ctl.sh status|start|restart|logs` → **验收: 非技术人员能看懂服务状态**

### L — Low to No Initial Cost
- [ ] 免费试点包 + 3 天 SOP → **验收: 标准交付物清单 + 演示脚本 + acme 成功案例截图**
- [ ] 容量锚点定价: 免费=单库 500 块内 / ¥5800=全库+素材工厂 / ¥18K=多租户+审计报表

### I — Instant Value
- [ ] 客户首次接入 <10 分钟 → **验收: 计时从打开上传页到看到命中率/缺口图 ≤10 分钟** (5 份文档→自动索引→价值仪表盘)
- [ ] 演示剧本: 10 个金标问题固定开场 + 缺口报告收尾 → **验收: 新人可复述并跑通**

### P — Plays Well in the Ecosystem
- [ ] 引用溯源=飞书/公众号链接 (已通, 保持)
- [ ] 素材工厂对接客户知识库 → 优先做"飞书云文档/文件夹一键同步"或"拖入即索引"
- [ ] 不改客户文档格式: md/pdf/Excel 直接进 (已支持)

## 3. 部署摩擦点排序 (执行顺序)

1. [ ] deploy_client.sh: HF/GFW + 环境安装合并, 一条命令零人工 (最高优先)
2. [ ] 客户文档自助接入: Streamlit 上传页 + 拖文件夹自动索引 (优先于多租户 UI)
3. [ ] Tailscale 激活: 跨机演示摩擦归零 (明天随 Mac mini 部署)
4. [ ] launchd 统一管理: ctl.sh (可延后, Mac mini 版已有雏形)
5. [ ] 密钥/LLM 配置项: DeepSeek 可换内网 LLM/本地 Qwen (骨架已有, 打包成配置)
6. [ ] 多租户完整化: 账号/权限 UI (最后, 企业采购阶段)

## 4. 未来 3 天节奏

- [ ] D1: Mac mini 部署 (deploy_macmini.sh) + Tailscale 激活 → 验证跨机演示
- [ ] D2: deploy_client.sh 写出并实测 → 15 分钟验收
- [ ] D3-7: 一周观察 kb_gap 命中率趋势 + 8502 噪声率 → "飞轮有效"证据页 → 进 MBS 销售脚本

## 5. 判定标准 (一周后)

- 命中率上升 + 噪声不劣化 → 飞轮有效, 升级销售话术为"你的知识库会自己变聪明"
- 命中率不动/噪声上升 → 暂停批量吞噬, 检查选题质量与分块策略 (先质量后产能)
