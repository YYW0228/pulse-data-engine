# 定价模型 (试点版 → 标准版 → 更新版)

> 版本: v1.0 | 2026-08-02
> 原则: 先验证付费意愿, 再扩功能; 用第一个客户逼出真实定价

---

## 三档定价

### 试点版 — 目的: 拿真实文档 + 案例授权
```
价格: 免费 或 3-8 千人民币
换取的: 
  1. 20-50 份真实文档
  2. 30-50 道金标问题 (客户标注)
  3. 案例授权 (脱敏后可用作销售弹药)
  4. 客户反馈 (打磨数据接入流程)
交付:
  1. 完整问答系统 (私有化部署)
  2. 验收报告 (P0/P1/P2)
  3. 后续升级优惠承诺
```

### 标准版 — 目的: 持续收入
```
价格: 2-8 万/年 (按知识库规模)
包含:
  1. 私有化部署 (systemd 或客户环境)
  2. 一次数据接入 (20-100 份文档)
  3. 基础维护 (系统更新/故障响应)
  4. 金标问题库维护
  5. 权限管理 (多角色)
不含: 法规自动更新管道 (见更新版)
```

### 更新版 — 中期: 差异化护城河
```
价格: 标准版 + 额外年费
包含:
  1. 法规自动更新管道 (自动拉取→解析→索引→通知)
  2. "知识库自动保持最新"能力
  3. 更新审计日志 (何时新增了哪条法规)
```

## 定价依据 (为什么值这个价)

```
客户替代方案对比:
  1. 自研: 3-6 个月 + 2-3 名工程师 + 30-50 万 → 高风险
  2. 通用 SaaS (如 Coze/Dify): 数据在外, 不可审计, 换文档要重配
  3. 咨询公司定制: 20-50 万一单, 不可复制
我们: 1-3 天上线 + 可审计 + 换文档零开发 + 持续维护
```

## 谈判红线

```
❌ 不做: 无限次免费迭代 (限 2 轮反馈)
❌ 不做: 替客户清洗脏数据 (只提供流水线, 客户给干净文档)
❌ 不做: 保证 100% 准确 (承诺引用溯源 + 人工闸门, 不承诺零幻觉)
✅ 做: 不满意不收费 (试点版)
```

## 付款节奏

```
试点: 一次性 (免费/3-8千)
标准: 首年预付 (部署费 + 年费), 次年续费
更新: 随标准版叠加, 年付
```
