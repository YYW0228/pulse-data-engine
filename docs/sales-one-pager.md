## 场景示例（已跑通）

**全球 AI 法规情报问答** (37 份报告, 124 块):
- 问 "WAICO 是什么组织" → 交叉引用 2 份报告, 给出组织性质/成员/意义
- 问 "2026 AI Agent 监管新规" → 融合情报 + 法规知识库综合回答
- 护栏: 注入/越权/误导问题全部拦截

## 交付流程

```
第 1 天: 客户提供 20-50 份文档 + 30-50 道真实问题
第 2-3 天: 我们跑流水线 (解析 → 索引 → 对抗验证 → 示例问答)
第 4 天: 共同验收 (P0 引用100% / P1 命中≥80% / P2 人工抽检)
后续: 换文档零开发成本, 增量更新
```

## 边界声明

- 不做自动决策, 不替代法务
- 所有回答带引用 + 人工确认闸门 (低置信度自动标记待复核)
- 全链路可审计、可追溯、数据不出域
- 内置幻觉/注入/越权防御
