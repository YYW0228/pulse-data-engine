## 五、收入 vs 成本 (定价合理性)

```
试点版: 3-8 千元/客户 (一次性) — 成本 ~$1.6/月 (5000问答)
  → 毛利 >99%, 成本几乎可忽略

标准版: 2-8 万/年 — 成本 <$20/月
  → 利润空间极大, 定价锚定的是"价值"不是"成本"

结论: 成本端完全不是约束, 现金流约束只在 VPS 续费时机
```

## 六、成本监控

```
- compliance_metrics.jsonl 记录每次问答成本 (log_rotate 每日归档)
- 8502 侧边栏实时显示总成本

```

## 七、预算底线

```
月硬上限: $50 (含 API + VPS 续费分摊)
  超出 = 异常 (刷量攻击/配置错误) → 立即排查

储备: 60 天现金流约束下, 成本可控 (<$100/月)
```
