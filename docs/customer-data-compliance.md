# 客户数据合规声明 (Data Compliance Statement)

> 版本: v1.0 | 2026-08-04
> 用途: 试点客户交付时随附的合规承诺 (P2-8)
> 原则: 数据不出域、可审计、可删除、可追溯

---

## 一、数据处理承诺

### 1. 数据不出域
```
客户文档存储在客户指定的私有化环境 (或我方 VPS 隔离区)。
我方 VPS 部署时: 客户数据存于独立目录 (data/customers/<客户名>/),
与全局知识库物理隔离, 不与其他客户数据混合。
```

### 2. 数据用途限定
```
客户文档仅用于:
  - 构建该客户的私有问答知识库
  - 回答该客户内部的合规/制度问题
不使用客户数据训练任何共享模型。
不向任何第三方披露客户文档内容。
```

### 3. 可删除性 (GDPR/个保法友好)
```
客户可随时要求删除其全部数据:
  删除命令: rm -rf data/customers/<客户名>/
  执行后: 客户数据 100% 清除 (含向量库/报告/日志中的引用)
  删除确认: 我方出具数据删除证明
```

### 4. 可审计性
```
每次问答生成完整 trace (决策链) 和证据包 (引用+依据)。
客户可导出全部问答日志用于审计。
所有回答带引用溯源, 不生成无依据的结论。
```

## 二、技术保障

| 保障项 | 实现 |
|--------|------|
| 数据隔离 | 每客户独立 DuckDB (data/customers/<名>/) |
| 访问控制 | 8502 知识库切换 (客户只能看自己的库) |
| 引用溯源 | 每个回答带 [文档: 文件 | 章节] |
| 人工复核 | 低置信度回答标记"待人工复核" |
| 删除能力 | 一条命令清除客户全部数据 |
| 传输安全 | 服务走 HTTPS/公网 IP, 文档上传经你方确认 |

## 三、边界声明 (诚实)

```
1. 我方不提供法律意见 — 回答仅供参考, 决策需人工/专业律师确认
2. 客户文档质量影响回答质量 — 我方会标注低置信度
3. 备份保留: 客户数据随 VPS 备份策略保留, 删除请求后 24h 内清除备份
4. 合规等级: 当前为"数据不出域+可删除"级别, 如需等保/等评, 另行评估
```

## 四、交付时随附

```
1. 本声明 (给客户)
2. 数据接入标准包 (docs/data-onboarding-kit.md)
3. 接入报告 REPORT.md (数据概况)
4. 验收金标 (30-50 题, 命中率 ≥80%)
5. 演示访问地址 + 客户专属知识库
```
